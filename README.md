# MOZA Pit House - Русская локализация (Русификатор)

Полный и качественный перевод программного обеспечения **MOZA Pit House** на русский язык. Этот проект создан для того, чтобы сделать интерфейс приложения более понятным и удобным для русскоязычного комьюнити симрейсеров.

## 📥 Установка

Для установки русификатора вам нужно заменить оригинальный файл перевода на скачанный из этого репозитория.

1. **Скачайте** актуальный файл перевода `mozapithouse_ru_RU.qm`.
2. **Закройте** программу MOZA Pit House, если она у вас запущена.
3. Перейдите в папку с установленной программой по следующему пути:
   ```text
   C:\Program Files (x86)\MOZA Pit House\bin\translations
   ```
   *(Если вы устанавливали программу в другое место, найдите папку `translations` в корневой директории MOZA Pit House).*
4. **Замените** находящийся там файл `mozapithouse_ru_RU.qm` на тот, который вы только что скачали.
5. **Запустите** MOZA Pit House. Если язык не изменился автоматически, зайдите в настройки приложения (Settings) и выберите русский язык.
